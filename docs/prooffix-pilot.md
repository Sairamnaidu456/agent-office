# ProofFix pilot

A bounded AI-assisted regression verification experiment for developers building web apps with coding agents. It takes a declarative browser plan, reproduces the reported failure on a local before version, and runs the same plan against a local after version. Only an assertion failure before and successful execution after can count as a verified regression repair. This does not establish that the whole application is correct.

## Product and evidence

Start with local Chromium, a small validated action/assertion vocabulary, frozen-plan hashes, before/after evidence, and an escaped portable HTML report. Plans may be produced by an AI agent using an exported prompt. The runner itself is deterministic; do not claim autonomous AI planning or inference has run unless a real integration is exercised. No broad exploration, arbitrary generated JavaScript execution, automatic code repair, production mutations, or hosted inference is included in the pilot.

Evaluate deliberately broken/fixed UI fixtures and negative controls. Measure whether the failure matches the intended assertion, false verification, repeatability, runtime and required intervention. A timeout or navigation failure is unverified. A passing before version does not prove a repair.
